# What It is?
- Gives All the Temporary files Created when, Pre-Processing, Compiling, Assembling, and Linking C Files.
- Use Flage: `-save-temps` in GCC to get the same files.
## The Files:
- `.i` File After Pre-Processing has completed.
- `.s` File After Compiler Converts Source code to assembly.
- `.o` File Assembler Converts assembly code to Machine Code known as object code. In C & GCC, The Compiler and Assembler are a packaged Product.
- `.out` or `.exe` Output Executable after Static or Dynamic Linking of object files.
